真实问题

标准 WES 流程可以完成比对、变异检测和注释，但最终仍会留下大量候选。研究者真正需要的是：哪个基因最值得继续做实验，以及这个判断由哪些可解释证据共同支持。

关键产品判断

标准流程与解释增强分层

底层 WES Pipeline 负责可靠地产出候选，上层 Evidence Fusion 负责疾病相关的排序与解释，避免职责混杂。

三类证据独立评分

分别计算正常细胞类型、疾病模型扰动和共表达网络支持，再展示每个候选的证据构成。

Profile 驱动疾病迁移

通过疾病 Profile 连接薄 CLI 与已有分析脚本，避免每换一个疾病就重新编写整套流程。

结构化结果直接进入网站

排名、证据分解、网络模块与运行摘要自动生成交互网站，缩短从分析到解释的距离。
