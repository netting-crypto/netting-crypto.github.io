真实问题

Codex 在本地电脑中运行，但用户不一定始终坐在电脑前。远程入口如果只创建一段新聊天，就会丢失已有 Workspace、Thread 和 Agent Context，无法真正延续桌面工作流。

关键产品判断

继续原任务，而不是创建新聊天

飞书会话绑定本地 Workspace 与指定 Codex Thread，普通消息直接延续原有上下文。

显式绑定与 Workspace Allowlist

远程消息只能进入允许的本地目录，会话绑定持久化保存，避免模糊或越界执行。

过程与结果分开回传

启动 Turn 后轮询 Rollout，把实时进度和最终回答分别返回飞书，减少远程等待的不确定性。

命令只处理控制面

bind、where、workspace、switch、new 等命令负责会话控制；绑定后自然语言直接进入当前任务。
