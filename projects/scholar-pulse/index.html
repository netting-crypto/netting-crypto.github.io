Scholar Pulse

每天抓取 ArXiv 论文，按你的兴趣用 RAG 排序，把值得读的发到邮箱，并从你的评分中持续学习。

项目概览

成熟度私人运行系统
我的职责产品设计 / Agent 编排 / RAG 排序
项目状态系统在本地长期运行，包含 ArXiv 抓取、RAG 排序、邮件发送与反馈闭环；GitHub 仓库当前为 Private。
真实问题

在 LLM、Agent、多模态这类快速演进的领域，研究者每天面对 100–300 篇新 ArXiv 论文。手动扫标题和摘要不仅耗时，还总会错过真正相关的工作。

关键产品判断

以兴趣画像驱动排序

把过去你高度评价的论文沉淀为兴趣 Profile，Ranker 只对“与你相关”的论文打分，而不是按热度排序。

三步 Agent 分工

Agent 1 负责抓取、Agent 2 做 RAG 排序（语义嵌入 + LLM 重排）、Agent 3 生成 HTML 邮件摘要，职责清晰。

邮件内评分 = 反馈闭环

你直接在邮件里打星，评分经反馈 Webhook 回写 CSV 并重建画像，让排序越用越准。

可观测的运行日志

每次运行写入 runs.jsonl，配 Live Dashboard 监控抓取、排序与发送的完整状态。
